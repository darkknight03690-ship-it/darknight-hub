# Proposal playbook

1. Extract only supplied facts from RFP / client inputs.
2. Choose smallest useful narrative archetype (see protiviti-pptx-agent `archetypes.md`).
3. Structure: cover → TOC → situation → approach → team/credentials (approved only) → timeline → commercials (if provided) → close.
4. Visuals: search ME Way Process / heatmap / infographic / Gantt packs before inventing diagrams.
5. Industry shells: use ME industry templates when vertical-specific (banking, energy, healthcare, government, ESG, aviation, TMT, manufacturing, AI, FS/RE).
6. QA against WORKING_AGREEMENTS.md + BRAND_AND_DECK_RULES.md before handoff.
